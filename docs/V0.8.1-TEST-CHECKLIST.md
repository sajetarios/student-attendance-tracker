# v0.8.1 practical acceptance checklist

## School Administrator
- [ ] Add Student shortcut opens the registration form.
- [ ] Add/edit student and photo actions work.
- [ ] Teacher and Gate Keeper accounts can be created.
- [ ] Class schedules can be created/managed.
- [ ] Gate Keeper monitoring list shows Gate Keeper activity for the selected date.
- [ ] Teacher gate attendance shows teacher time-in/time-out records for the selected date.
- [ ] Official SF2 submissions can be collected.

## Department Head
- [ ] Department Head dashboard opens, not Student Management.
- [ ] Student roster, QR scanner, and student editing are unavailable.
- [ ] Teacher grade/section, assigned schedules, leave, and coverage can be monitored.
- [ ] Submitted SF2 reports can be viewed/downloaded but not collected.
- [ ] Temporary substitute coverage follows server-side authorization.

## Subject Teacher
- [ ] Only assigned subject/advisory learners are shown.
- [ ] Student edits are limited to permitted fields and assigned scope.
- [ ] Can create a subject schedule for a selected grade and section.
- [ ] Existing subject schedule assignments remain present.
- [ ] Personal SF2 copy is downloaded as a non-empty workbook and clearly marked NOT OFFICIAL.
- [ ] Missing records are displayed as NR, not automatically as Absent.

## Class Adviser
- [ ] Assigned grade and section are shown.
- [ ] Can view and edit learners only within permitted advisory scope.
- [ ] Can register learners if the account has the Class Adviser designation and policy permits.
- [ ] Can generate and submit the official consolidated SF2 for the assigned section.

## Gate Keeper
- [ ] Gate-only workspace is shown; no full roster/reporting menu.
- [ ] Attendance selector offers Automatic, Learner only, and Teacher only.
- [ ] Learner QR and teacher QR are recognized as the correct person type.
- [ ] Registered photo is displayed and visibly flashes/highlights.
- [ ] Time-in/time-out buttons remain disabled until photo match is confirmed.
- [ ] Teacher and learner punches are recorded to the correct attendance stream.

## Parent / Student
- [ ] Parent sees only approved linked children.
- [ ] Student sees only their own profile and attendance.
- [ ] Neither account can access school management routes.

## Responsive and usability
- [ ] Verify desktop, tablet, and phone widths.
- [ ] Verify horizontal table scrolling on narrow screens.
- [ ] Verify keyboard focus is visible and reduced-motion preference is respected.
- [ ] Verify camera works on a trusted HTTPS origin on supported phones/tablets.
- [ ] Verify SF2 file download in the actual browser.

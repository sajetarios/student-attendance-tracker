# Install and verify v0.8.2

## Install side-by-side

1. Stop the currently running server with `Ctrl+C`.
2. Extract this ZIP to `C:\SchoolAttendance-Test-v082`. Do not overwrite your existing project.
3. Copy your existing `.env` from the working v0.8.1 folder into the new folder. Keep `DATABASE_URL` pointing to your existing test database `school_attendance_backup_test`. Never share `.env` or passwords.
4. Copy the entire existing `storage` folder into the new project, replacing the placeholder `storage/README.txt`. This preserves student/teacher photos and generated reports referenced by the database. Do not place storage inside `public`.
5. Copy the current HTTPS certificate and private key files into the new project if you use HTTPS. Keep private keys private.
6. Open PowerShell in `C:\SchoolAttendance-Test-v082` and run:

```powershell
npm.cmd install
npm.cmd test
npm.cmd run db:migrate
npm.cmd start
```

No v0.8.2 database migration is added. The migration command should find the existing migrations already applied and make no changes. Do not run `db:reset:test` or `db:adopt-existing-test`.

## Open pages

- Login: `http://localhost:3001/portal-login.html`
- Management Portal: `http://localhost:3001/portal.html`
- Attendance Desk: `http://localhost:3001/`

Use your computer's LAN IP instead of `localhost` on another device. Camera use on a phone/tablet requires a trusted HTTPS origin and camera permissions.

## Acceptance checks

1. Sign in as School Administrator. Open Students. Confirm Add Student is visible; verify the roster has photo thumbnails/placeholders and QR previews.
2. Open Teachers. Confirm the teacher account table appears, not the learner table. Confirm teacher names, designation, status, schedule, and actions are in the teacher list.
3. Sign in as Subject Teacher. Open My assigned learners. Confirm only assigned learners are shown and their QR previews load. The Add Student action is intentionally hidden for a subject-only teacher.
4. Open Personal SF2 copy. Preview the report, click Generate personal copy, and confirm a non-empty `.xlsx` workbook downloads. It must be labelled NOT OFFICIAL. NR is not an absence.
5. Sign in as a Class Adviser. Confirm assigned-section learner actions and official consolidated SF2 submission are available only for the assigned section.
6. Check missing photos. If “Missing” appears, restore the correct `storage/student-photos` folder or re-upload the image. “No photo” means no photo is currently registered.
7. Confirm the browser loaded `/comfort-ui.css?v=0.8.2`; if older colors remain, hard-refresh with `Ctrl+Shift+R` and unregister the old service worker.

These checks require the user's local PostgreSQL database and browser. Do not treat automated unit tests as proof of live integration.

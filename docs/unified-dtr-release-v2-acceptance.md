## Non-negotiable
- Preserve prior records, approved documents, credit history, school/employee settings and permissions. Never fabricate or backdate a punch. No automatic entitlement, overtime, payroll, or credit decisions without certified policy and evidence.
- Ordinary incomplete duty counts at most complete verified sessions, with separate evidence-day count. Reversed chronology is review-only. Unconfigured prescribed hours block report readiness. Pending applications must not confer approved leave.
- Keep Department Head recommendation and eligible missing-scan decisions, Principal final staff leave/OB authorization, School Admin documented credit verification and report review, and documented external authority for Principal's own applications. No self-approval.
- Full automated scenario matrix must include expected DTR slots, leave/OB remarks, minutes, attendance totals, exception flags, role actions, credit deltas and report readiness. Tests must invoke actual production logic and APIs, not merely assert wording or mock the entire workflow. Preserve existing security and regression tests.
- Verify all existing applicable CI workflows and new tests against the exact final PR head. Use migrated disposable PostgreSQL with synthetic historical data, authenticated browser journeys and isolated staging with no production secrets/data. Verify offline browser lifecycle on representative supported engines; acknowledge real-device limitations rather than claiming a browser simulation guarantees device behavior.
- Review CSC/DepEd rules and school-specific certified policy before new entitlement, LWOP, leave counting, or official report behavior is authorized. Do not invent policy.
- Only after the complete gate passes: check current production base, rebase if needed, rerun exact-head checks, verify staging migration and rollback readiness, promote one release and confirm exact Render live deployment. No intermediate candidate deployment and no recurring teacher scenario testing.

# Install v0.8.1 over your existing test database

## 1. Keep the current installation

Do not delete the current project. Keep it as your rollback copy.

Extract the v0.8.1 ZIP into a new folder, for example:

```text
C:\SchoolAttendance-Test-v081
```

## 2. Copy local configuration and files

From your current working version, copy into the new folder:

- `.env` (keep its `DATABASE_URL` pointed to `school_attendance_backup_test`)
- the contents of `storage` (student/teacher photos and generated local reports)
- your local HTTPS private key and certificate files, if configured

Do not upload or share `.env`, private keys, or student photos.

## 3. Install and check

Open PowerShell in the new folder and run:

```powershell
npm.cmd install
npm.cmd test
npm.cmd run db:migrate
npm.cmd start
```

The migration runner should report migrations 001–008 as already applied, or apply only a missing baseline migration. No new v0.8.1 migration exists. Do not run `db:reset:test` or `db:adopt-existing-test`.

## 4. Open the pages

- Management Portal: `http://localhost:3001/portal-login.html`
- Attendance Desk: `http://localhost:3001/`
- Parent registration: `http://localhost:3001/parent-register.html`

Sign in with the appropriate account type. Use a separate browser profile or sign out when changing between Parent, Student, and school accounts.

## 5. First checks

1. As School Administrator, confirm Add Student is visible and the Gate Keeper monitoring and teacher gate attendance tables load.
2. As Subject Teacher, confirm only assigned learners appear, student edit access follows the teacher scope, and the personal SF2 copy downloads.
3. As Class Adviser, confirm the assigned section appears and official SF2 submission is available only for that assigned section.
4. As Department Head, confirm student registration/QR scanning and official SF2 collection are unavailable; monitoring pages remain read-only except approved temporary substitution coverage.
5. As Gate Keeper, choose Learner, Teacher, or Automatic scanning. Confirm the photo, then record time-in/time-out.
6. As Parent and Student, confirm each account sees only its own linked child or own learner attendance.

The automated tests do not replace live camera, photo, database, file download, or offline-sync testing.

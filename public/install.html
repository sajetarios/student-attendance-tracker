Install Attendigo

Open the school app directly from your phone. No app store needed. / Buksan ang app mula sa Home Screen.

You're using Attendigo as an app

Continue to sign in. / Magpatuloy sa pag-sign in.

iPhone or iPad

  1. Open this page in Safari. / Buksan sa Safari.
  2. Tap Share (square with an upward arrow). / Pindutin ang Share.
  3. Choose Add to Home Screen, keep Open as Web App enabled if shown, then tap Add. / Piliin ang Add to Home Screen, pagkatapos ay Add.
  4. Open the Attendigo icon on your Home Screen. / Buksan ang Attendigo icon.

Android phone or tablet

  1. Open this page in Chrome. / Buksan sa Chrome.
  2. Tap Install Attendigo above if available, or tap the three-dot browser menu. / Pindutin ang Install o ang tatlong tuldok.
  3. Choose Install app or Add to Home screen, then confirm. / Piliin ang Install app o Add to Home screen.
  4. Open the new Attendigo icon. / Buksan ang Attendigo icon.

Install from your browser

Use the Install Attendigo button if available, or look for Install app in your browser's menu or address bar. / Hanapin ang Install app sa browser.

Open in your phone's browser

You're in an in-app browser. Use its menu to open in Safari on iPhone or Chrome on Android, or copy the link below. / Buksan sa Safari o Chrome.

Share with others / Ibahagi

Parents / Magulang: After opening the installed app, sign in and tap Activate phone alerts in the Parent Portal. Notifications need your permission and a supported device.
